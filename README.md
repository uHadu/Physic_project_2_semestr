# Задание 7.1. Закон Ома для участка цепи

| | |
|---|---|
| **Цель** | Построить вольт-амперную характеристику резистора |
| **Задача** | Измерить ток при разных напряжениях и убедиться в линейности |
| **Визуализация** | Схема с резистором, амперметром, вольтметром (доп функционал: пользователь может ввести любой прибор при помощи массива измерений или формулы и добавить свой прибор) |
| **Управление** | Сопротивление $R$, напряжение $U$ (слайдер) |
| **Расчётный модуль** | $I = U/R$ |
| **Вычислительный эксперимент** | Найти $R$ из наклона графика $I(U)$ |
| **Графики и вывод** | График $I(U)$ с аппроксимацией; таблица $R_{\text{задан}}$, $R_{\text{эксп}}$ |

---

## 1. Теоретические основы

Для однородного участка цепи (без сторонних сил) сила тока пропорциональна приложенному напряжению — **закон Ома**:

$$
I = \frac{U}{R} = G\,U, \qquad G = \frac{1}{R}
$$

где $I$ — сила тока, А; $U$ — напряжение на участке, В; $R$ — сопротивление, Ом; $G$ — проводимость, См.

Сопротивление проводника определяется материалом и геометрией:

$$
R = \rho\,\frac{l}{S}
$$

где $\rho$ — удельное сопротивление, $l$ — длина, $S$ — площадь поперечного сечения.

Зависимость $I(U)$ называется **вольт-амперной характеристикой (ВАХ)**. Для омического проводника при постоянной температуре ВАХ линейна и проходит через начало координат, а её угловой коэффициент равен проводимости:

$$
k = \frac{dI}{dU} = \frac{1}{R} \quad\Rightarrow\quad R = \frac{1}{k}
$$

**Условие применимости.** Линейность сохраняется, пока резистор не нагревается, так как сопротивление металлов зависит от температуры:

$$
R(T) = R_0\,(1 + \alpha\,\Delta T)
$$

Поэтому выделяемая мощность $P = U^2/R$ должна быть мала. В модели её следует ограничить допустимой мощностью резистора $P_{\max}$.

---

## 2. Схема измерений

Амперметр включается **последовательно** с резистором, вольтметр — **параллельно**. Реальные приборы имеют внутреннее сопротивление ($R_A \neq 0$, $R_V \neq \infty$), что приводит к систематической погрешности метода, зависящей от схемы включения.

В модели цепь собирается так: **источник ЭДС $\mathcal{E}$ → ключ K** (сразу после источника, до амперметра) **→ амперметр A → резистор R →** обратно к источнику. Вольтметр V подключается параллельно резистору (схема А) или параллельно цепочке «амперметр + резистор» (схема Б). Приборы на схеме — круги A и V; показания выводятся только по запросу (`show_readings=True`) и берутся из ядра.

### Схема А — вольтметр подключён непосредственно к резистору

Амперметр измеряет сумму токов через резистор и вольтметр:

$$
I_{\text{изм}} = \frac{U}{R} + \frac{U}{R_V}
\quad\Rightarrow\quad
R_{\text{изм}} = \frac{U}{I_{\text{изм}}} = \frac{R\,R_V}{R + R_V} < R
$$

### Схема Б — вольтметр подключён к цепочке «амперметр + резистор»

Вольтметр измеряет сумму напряжений на резисторе и амперметре:

$$
U_{\text{изм}} = I\,(R + R_A)
\quad\Rightarrow\quad
R_{\text{изм}} = R + R_A > R
$$

### Критерий выбора схемы

| Условие | Предпочтительная схема |
|---|---|
| $R \ll \sqrt{R_A R_V}$ (малые сопротивления) | А |
| $R \gg \sqrt{R_A R_V}$ (большие сопротивления) | Б |

---

## 3. Расчётный модуль

**Входные параметры (слайдеры):** $R$, ЭДС источника $\mathcal{E}$ (в формулах ниже $U_{\text{ист}} = \mathcal{E}$).

**Внутренние параметры модели:**

| Параметр | Рекомендуемое значение | Как задаётся в ядре (`components.py`) |
|---|---|---|
| Сопротивление амперметра $R_A$ | 0,1 – 1 Ом | `Ammeter(R_A=...)`, по умолчанию 0,5 Ом; `R_A=0` — идеальный амперметр |
| Сопротивление вольтметра $R_V$ | $10^4$ – $10^6$ Ом | `Voltmeter(R_V=...)`, по умолчанию 1 МОм; `R_V=inf` — идеальный вольтметр |
| Класс точности приборов $\gamma$ | 0,5 – 2,5 % | `accuracy_class=...` у амперметра и вольтметра, по умолчанию 0,5 % |
| Разрешение прибора | — | `counts=...` — отсчётов на предел (по умолчанию 2000), цена деления = предел / `counts` |
| Пределы измерения | — | `ranges=...`, предел выбирается автоматически (наименьший, в который помещается величина) |
| Внутреннее сопротивление источника $r$ | 0 | `VoltageSource(emf=..., r=...)`, по умолчанию 0 |
| Сопротивление замкнутого ключа | — | `Switch(closed=True, R_on=...)`, по умолчанию 1 мОм |

### Показания приборов (схема А)

$$
R_{\text{экв}} = \frac{R\,R_V}{R + R_V}, \qquad
I_{\text{цепи}} = \frac{U_{\text{ист}}}{R_A + R_{\text{экв}}}
$$

$$
U_{\text{изм}} = I_{\text{цепи}}\,R_{\text{экв}} + \xi_U, \qquad
I_{\text{изм}} = I_{\text{цепи}} + \xi_I
$$

### Показания приборов (схема Б)

$$
I_{\text{изм}} = \frac{U_{\text{ист}}}{R + R_A} + \xi_I, \qquad
U_{\text{изм}} = U_{\text{ист}} + \xi_U
$$

### Модель погрешности приборов

$\xi_U$, $\xi_I$ — случайные погрешности, распределены равномерно в интервале $[-\Delta;\,+\Delta]$, где Δ = γ·предел/100 %. Класс точности задаёт предельную (максимальную) погрешность прибора:

$$
\Delta U = \frac{\gamma\,U_{\text{пред}}}{100\%}, \qquad
\Delta I = \frac{\gamma\,I_{\text{пред}}}{100\%}
$$

Показания округляются до цены деления (разрешения) прибора.

> В идеальном случае ($R_A \to 0$, $R_V \to \infty$, $\xi = 0$) модель сводится к $I = U/R$.

## 4. Вычислительный эксперимент: определение $R$ по наклону

1. Задать $R_{\text{задан}}$.
2. Изменяя $U$ (например, от 1 до 10 В с шагом 1 В, $n = 10$ точек), записать пары $(U_i, I_i)$ в таблицу.
3. Аппроксимировать данные прямой $I = kU$ методом наименьших квадратов (через начало координат):

$$
k = \frac{\sum U_i I_i}{\sum U_i^2}, \qquad R_{\text{эксп}} = \frac{1}{k}
$$

4. Оценить погрешность коэффициента наклона и сопротивления:

$$
S_k = \sqrt{\frac{\sum (I_i - kU_i)^2}{(n-1)\sum U_i^2}}, \qquad
\Delta R = \frac{S_k}{k^2}\cdot t_{\alpha,\,n-1}
$$

где $t_{\alpha,\,n-1}$ — коэффициент Стьюдента ($\approx 2{,}26$ для $n = 10$, $\alpha = 0{,}95$).

5. **Проверка линейности.** Дополнительно аппроксимировать данные прямой $I = kU + b$: для омического проводника свободный член $b$ должен быть равен нулю в пределах погрешности, коэффициент детерминации $R^2 \approx 1$.

6. **Сравнение с заданным значением:**

$$
\delta = \frac{|R_{\text{эксп}} - R_{\text{задан}}|}{R_{\text{задан}}}\cdot 100\%
$$

---

## 5. Графики и вывод

**Выходные данные:**

- график $I(U)$ — экспериментальные точки с крестами погрешностей и аппроксимирующая прямая;
- таблица результатов:

| $R_{\text{задан}}$, Ом | Схема | $R_{\text{эксп}} \pm \Delta R$, Ом | $\delta$, % |
|---|---|---|---|
| … | А / Б | … | … |

**Ожидаемый результат.** ВАХ резистора линейна, $R_{\text{эксп}}$ совпадает с $R_{\text{задан}}$ в пределах погрешности. При проведении эксперимента для малого и большого $R$ в обеих схемах проявляется систематическая ошибка метода. Например, при $R = 10^5$ Ом и $R_V = 10^6$ Ом схема А занижает результат примерно на 9 %, что наглядно показывает, почему схему включения выбирают в зависимости от величины измеряемого сопротивления.

## Как запустить

Нужен Python 3.10+. Все команды выполняются из корня репозитория.

```bash
pip install -r requirements.txt
```

Интерфейс (выбор схемы, слайдеры R, ℰ, R_A, R_V, γ, n, кнопка «Провести эксперимент»):

```bash
streamlit run src/app.py
```

Вычислительный эксперимент: R = 1 Ом, 100 Ом, 10 кОм, 100 кОм в схемах А и Б, таблица и графики в `results/`:

```bash
python src/experiment.py
```

Только рисунок схем А и Б (`results/circuit_schemes.png`):

```bash
python src/circuit_view.py
```

Тесты:

```bash
python -m pytest
```
