# Как интерфейс и обработка подключаются к ядру

Ядро — `solver.py` и `components.py` в корне репозитория (автор — напарник).
Код в `src/` его **не изменяет** и **не дублирует**: цепь считает только ядро.

## Точка подключения

`src/core_api.py` — единственный модуль, который импортирует ядро. Он добавляет
корень репозитория в `sys.path` и реэкспортирует нужные классы.

## Что берётся из ядра

| Шаг | Где в `src/` | Вызов ядра |
|---|---|---|
| Сборка схемы | `presets.py` | `VoltageSource`, `Switch`, `Ammeter`, `Resistor`, `Lamp`, `Voltmeter`, `Circuit([...])` |
| Изменение ЭДС | `experiment.run_series` | `circuit["E"].set_param("emf", u)` |
| Расчёт | `experiment.run_series` | `circuit.solve(x0=предыдущее.x, auto_burn=True)` |
| Показания | `experiment.run_series` | `sol.reports(noise=True, seed=...)` → `reading`, `error`, `overload` |
| Предупреждения | `experiment.run_series` → `app.py` | `sol.warnings`, флаги `overheated`, `burned` |
| Ошибки | `app.py` | `ElementError` (сборка), `CircuitError` (расчёт) |
| Показания на схеме | `circuit_view.draw_circuit(readings=...)` | показания приборов из `reports` |

## Схема узлов (одинаковая во всех готовых схемах)

```
E: p(+) — 0(−)      ключ K: p — k      амперметр A: k(+) — a(−)
нагрузка: a — 0     вольтметр V: a — 0 (схема А)  или  k — 0 (схема Б)
```

## Тонкости

* `sol.reports(seed=s)` каждый раз создаёт новый `random.Random(s)`. Если отдать один и тот же
  `seed` во все точки, ошибка в каждой точке будет одинаковой, то есть систематической.
  Поэтому `run_series` выводит из seed серии свой seed для каждой точки.
* Показание `reading` округляется до разрешения прибора даже при `noise=False`.
  Чтобы получить чистую ошибку метода, используются истинные `U`, `I` из отчёта прибора
  (`Series.U_true`, `Series.I_true`).
* Кресты погрешностей на графике — поле `error` ядра: Δ = γ·предел/100 %
  (предельная погрешность, шум равномерен в [−Δ; +Δ]).
* Лампа после перегорания остаётся с `burned = True`, поэтому каждый эксперимент
  собирает цепь заново (`presets.build(...)`).
