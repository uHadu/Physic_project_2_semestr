# Ядро симулятора цепей постоянного тока

Пользователь собирает цепь из шаблонов элементов, ядро считает токи и напряжения во всех ветвях и выдаёт показания приборов и данные для графиков.

## Файлы

| Файл | Что внутри |
|---|---|
| `components.py` | Шаблоны элементов: параметры, готовые модели, физика каждого элемента |
| `solver.py` | Расчёт цепи узловым методом (MNA) + итерации Ньютона для нелинейных элементов |
| `netlist.py` | Задание цепи текстом или списком словарей (JSON из интерфейса) |
| `analysis.py` | Развёртка по параметру (вычислительный эксперимент), МНК, R по наклону ВАХ |
| `plot_data.py` | Данные для графиков — ничего не рисует, только числа и подписи |

Зависимость одна — `numpy`.

## Быстрый старт

```python
from netlist import parse_netlist
from analysis import sweep, linspace, fit_resistance
from plot_data import iv_plot

c = parse_netlist("""
source    E1 n1 0   10
ammeter   A1 n1 n2  R_A=0.5
resistor  R1 n2 0   100k
voltmeter V1 n2 0   R_V=1M
""")

sol = c.solve()                       # один расчёт
r = sol.reports(noise=True)           # отчёт по всем элементам
r["A1"]["reading"], r["V1"]["reading"]

sw = sweep(c, "E1.emf", linspace(1, 10, 10), ["V1.reading", "A1.reading"], noise=True)
fit = fit_resistance(sw.column("V1.reading"), sw.column("A1.reading"))
iv_plot(sw, "V1.reading", "A1.reading", fit=fit, R_theory=100e3).to_json("iv.json")
```

## Как пользователь задаёт цепь

**Текстом** — одна строка на элемент:

```
<тип> <имя> <узлы...> [главный параметр] [ключ=значение ...]
```

Земля — узел `0` (или `gnd`, `земля`). Числа понимают приставки и единицы: `100k`, `2,2МОм`, `50мА`, `1M` (мега), `1m` (милли), `inf`.

**Словарями** (так удобнее интерфейсу):

```python
from netlist import circuit_from_specs
c = circuit_from_specs([
    {"type": "source", "name": "E1", "nodes": ["a", "0"], "emf": 12, "r": 0.5},
    {"type": "lamp",   "name": "L1", "nodes": ["a", "0"], "model": "6V_3W"},
])
c.to_specs()   # обратно в список словарей — для сохранения
```

Изменить параметр на лету: `c["K1"].set_param("closed", False)`. Добавить и удалить элемент: `c.add(...)`, `c.remove("R1")`.

`components.catalog()` возвращает описание всех шаблонов: выводы, параметры с единицами и значениями по умолчанию, готовые модели. По нему интерфейс может сам построить палитру элементов и формы ввода.

## Шаблоны

| Тип | Выводы | Главный параметр | Остальные параметры | Готовые модели |
|---|---|---|---|---|
| `source` — источник ЭДС | `+ −` | `emf` | `r` — внутреннее сопротивление | `батарейка_AA`, `крона_9V`, `лабораторный` |
| `resistor` — резистор | `a b` | `R` | `P_max` | — |
| `lamp` — лампа накаливания | `a b` | `U_nom` | `P_nom`, `cold_ratio`, `burn_factor`, `T0`, `burned` | `6V_3W`, `12V_5W`, `3.5V_0.26A`, `2.5V_0.3A`, `230V_60W` |
| `switch` — ключ | `a b` | `closed` | `R_on` | — |
| `custom` — пользовательский элемент | `a b` | `formula` | `table`, `label` + **любые свои параметры** | — |
| `ammeter` — амперметр | `+ −` | `R_A` | `ranges`, `accuracy_class`, `counts` | `идеальный`, `мультиметр`, `школьный` |
| `voltmeter` — вольтметр | `+ −` | `R_V` | `ranges`, `accuracy_class`, `counts` | `идеальный`, `мультиметр`, `цифровой_10М`, `школьный` |

Ток двухполюсника считается положительным, если он течёт от первого вывода ко второму.

## Физические модели

**Расчёт цепи.** Неизвестные — потенциалы узлов и токи ветвей источников и амперметров. Для каждого узла записывается первый закон Кирхгофа, для каждой ветви — её уравнение: $\varphi_+ - \varphi_- - r\,i = \mathcal{E}$. Нелинейные элементы (лампа, пользовательский) линеаризуются в текущей точке, и система решается методом Ньютона до сходимости. Чтобы висящие узлы не делали систему вырожденной, каждый узел связан с землёй проводимостью $10^{-12}$ См.

**Лампа.** Сопротивление нити растёт с температурой: $R = R_0(1+\alpha\Delta T)$. Нагрев задаётся тепловым балансом $\Delta T = P/G_{th}$, где $P = U^2/R$. Отсюда

$$R(U) = \frac{R_0 + \sqrt{R_0^2 + 4R_0 a U^2}}{2}, \qquad a = \frac{k-1}{P_{ном}}, \quad k = \frac{R_{гор}}{R_0}.$$

ВАХ получается нелинейной: при малых $U$ сопротивление равно $R_0$, при номинале $R = U_{ном}^2/P_{ном}$. Температура нити определяется по $\Delta T = (R/R_0 - 1)/\alpha_W$, где $\alpha_W = 4{,}5\cdot10^{-3}$ К⁻¹. Если $P > k_{burn}\,P_{ном}$, выставляется флаг `will_burn`. При `solve(auto_burn=True)` лампа перегорает, то есть размыкается.

**Пользовательский элемент.** Пользователь сам решает, какие параметры есть у его элемента, и задаёт ВАХ одним из двух способов.

*Формулой* $I(U)$ со своими параметрами:

```
custom X1 a b formula="U / (R0 * (1 + k*U**2))" R0=100 k=0.05 label="Мой элемент"
```

В формуле можно использовать `+ - * / **` (или `^`), скобки, числа, `U`, имена своих параметров, `pi`, `e` и функции `sqrt exp log ln log10 abs sign sin cos tan tanh sinh cosh atan min max`. Формула разбирается по синтаксическому дереву: всё, кроме перечисленного (атрибуты, индексы, вызовы других функций, `lambda`...), отклоняется. Поэтому выполнить через неё произвольный код нельзя.

*Таблицей точек* $(U, I)$, например снятых на реальной установке:

```
custom X2 a b table="0:0, 0.5:0.001, 1:0.01, 1.5:0.06, 2:0.2"
```

Между точками ВАХ интерполируется линейно, за краями продолжается крайний отрезок. Если в таблице только $U \ge 0$, ВАХ считается симметричной: $I(-U) = -I(U)$.

В отчёте элемент возвращает статическое сопротивление $U/I$, дифференциальное $dU/dI$ и свои параметры. Если $I(0) \ne 0$, выдаётся предупреждение: такой элемент ведёт себя как источник. Если формула не определена при части напряжений (например, `sqrt(U)` при $U<0$), тоже выдаётся предупреждение.

**Ключ.** В замкнутом состоянии это резистор $R_{on}$, в разомкнутом — разрыв.

**Приборы.** Внутреннее сопротивление учитывается в цепи. Показание формируется так: автовыбор предела, погрешность $\Delta = \gamma\cdot\text{предел}/100\%$, случайная ошибка, равномерная в $[-\Delta;\,\Delta]$ (включается `noise=True`), округление до разрешения дисплея. Если величина превышает все пределы, ставится `overload = True` и `reading = None`.

## Что возвращает отчёт элемента

| Элемент | Поля |
|---|---|
| все двухполюсники | `U`, `I`, `P` |
| резистор | `overheated` |
| лампа | `R`, `T` (К), `brightness` (доля номинальной мощности), `burned`, `will_burn` |
| источник | `P_internal` |
| пользовательский | `R_static` ($U/I$), `R_diff` ($dU/dI$), `param.<имя>` — свои параметры |
| приборы | `reading`, `error`, `limit`, `resolution`, `overload` |

Любое из этих полей можно снимать в развёртке: `"L1.T"`, `"X1.R_static"`, `"A1.reading"`, а потенциал узла — `"V:n2"`.

## Данные для графиков

`PlotData` содержит `title`, `x_label`, `y_label` и список `series`. Каждая серия — это `name`, `x`, `y`, `x_err`, `y_err` и `style` (`points`, `line` или `dashed`). Единицы осей подбираются автоматически (мкА, мА, кОм...), значения в сериях уже пересчитаны в них. Экспорт: `to_dict()`, `to_json()`, `to_csv()`. Пример отрисовки на matplotlib приведён в начале `plot_data.py`.

## Ошибки

Неверный ввод вызывает `ElementError`: неизвестный тип, отрицательное сопротивление, не то число выводов. Цепь, которую нельзя решить, вызывает `CircuitError`: нет земли, короткое замыкание идеального источника, расчёт не сошёлся. Текст ошибок на русском, его можно показывать пользователю как есть. Некритичные проблемы (например, висящий вывод) попадают в `sol.warnings`.
